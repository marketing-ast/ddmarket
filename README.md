# DD Market

DD Market - статический каталог продуктов с корзиной и заказом через WhatsApp. Сайт берет товары и цены из опубликованной Google Таблицы, показывает весовые и штучные товары, выделяет проблемные цены и формирует готовый текст заказа.

## Что внутри

- `index.html` - разметка каталога, корзины и навигации.
- `style.css` - mobile-first дизайн DD Market по брендбуку.
- `app.js` - загрузка CSV из Google Sheets, фильтры, корзина, кеш и WhatsApp.
- `data/ddmarket-products.csv` - резервная выгрузка текущего каталога.
- `scripts/category_sync.py` - автоматические категории, выпадающие списки и постоянные ID через существующий сервисный аккаунт.
- `scripts/convert-client-catalog.js` - конвертер клиентского Excel в формат каталога.
- `assets/fonts/` - локально подключенный фирменный шрифт Onest.
- `logo/` - логотип DD Market для интерфейса.

## Таблица Товаров

Сайт читает опубликованный CSV:

```text
https://docs.google.com/spreadsheets/d/e/2PACX-1vQy0tUi3LVSJ_o7DMI_2OAFxr-651J5wgDJBnL0cNq18YNAltbsgEPwYO0QDp4p00mOrwhY1i3IrT_m/pub?output=csv
```

Ожидаемые колонки:

```text
id,publish,barcode,name,name1s,unit,category0,category1,price,ostatok,sale,image,comment,ostatok_1c,reserve,min_qty,ruchnoi_ostatok
```

Правила:

- `barcode`: штрихкод товара, участвует в поиске.
- `publish`: `yes` публикует товар, `no` скрывает его от сайта.
- `unit`: `кг` для весовых товаров, `шт` для упаковок и штучных товаров.
- `category0`: верхняя категория для первого ряда навигации на сайте.
- `category1`: категория внутри `category0`, показывается вторым рядом.
- `price`: сайт показывает только товары с ценой больше нуля.
- `ostatok`: постоянная формула автоматического остатка для сайта. Она считает запас из `ostatok_1c`, `reserve`, `min_qty` и `unit`; пустой `reserve` означает `0%`, а пустой `ostatok_1c` даёт `0`. Числовое значение ограничивает количество, которое покупатель может добавить в корзину; `0` скрывает товар из каталога.
- `ruchnoi_ostatok`: необязательный ручной остаток. Корректное число имеет приоритет над `ostatok`: `0` скрывает товар, положительное число ограничивает заказ этим значением. Бот всё равно рассчитывает и обновляет автоматический остаток в `ostatok`; после очистки `ruchnoi_ostatok` сайт сразу переключается на актуальную логику 1С (`ostatok_1c` → `reserve` → `min_qty`).
- `sale`: пока всем `no`.
- `image`: необязательная ссылка на фото товара.
- `comment`: ручной комментарий, на сайт не выводится как служебная диагностика.


Сайт игнорирует строки без `barcode`, с `publish=no`, без валидной цены и с остатком `0`.

## Добавление категорий

Добавьте категорию и подкатегорию в `categories!A:B`. Серверный сервис заполнит
технические поля и обновит списки обычно за 15–30 секунд. Новому заполненному товару
с пустым ID присваивается постоянный номер; существующие ID сохраняются.
Порядок меню берётся из `sort0`/`sort1`. Подробности и откат: [docs/category-automation.md](docs/category-automation.md).
